# Expenso – Expense Tracker iOS App

An iOS app to track daily income and expenses, built with SwiftUI, CoreData and the MVVM architecture.

## Features
- Add, edit and delete income and expense transactions
- Dashboard with income and expense charts
- Filter transactions
- Export transactions to CSV
- Face ID / Touch ID authentication
- Light and dark mode
- Offline storage with CoreData

## Tech Stack
Swift · SwiftUI · CoreData · Charts · Lottie · CocoaPods
